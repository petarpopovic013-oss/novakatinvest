# Novak Invest page topology

## Globalno

1. Sticky header: logo, četiri PRD linka, prodajni CTA, mobilni meni.
2. Main sadržaj konkretne rute.
3. Globalni footer: kontakt, navigacija, projekti, pravne napomene.

## Početna

1. Hero — Temerinska 141, primarni i sekundarni CTA.
2. Aktuelna demo ponuda — Temerinska 141, Petrovaradin, Sremska Kamenica.
3. Zašto Novak Invest — iskustvo, kvalitet, lokacije, odnos sa kupcima.
4. Standard gradnje — keramika, podovi, unutrašnja i fasadna stolarija.
5. Reference preview — Atrium Residence i Gundulićeva 33, uz status za potvrdu.
6. Centralni prodajni CTA.

## Unutrašnje rute

- O nama: profil, vrednosti, proces, CTA.
- Ponuda: aktivni/demo projekti bez filtera.
- Projekat: činjenice, sadržaj, jedinice ili demo prazno stanje.
- Stan: status, činjenice, tlocrt kada postoji, prodajni CTA.
- Reference: listing projekata klasifikovanih kao reference u demo data sloju.
- Referenca detalj: osnovne činjenice, galerija kada postoji, CTA ka ponudi.
- Kontakt: centralni podaci i demo forma.

## Interakcioni modeli

- Header: sticky na skrolu; mobilni meni click-driven.
- CTA i kartice: hover/focus tranzicije.
- Kontakt forma: client-side demo success stanje.
- Mobilni prodajni bar: sticky/fixed na projektnim i unit stranicama.
