# Global shell specification

## Cilj

Globalni Novak Invest header i footer za sve rute iz PRD-a.

## Header

- sticky svetla kartica unutar glavnog paper kontejnera;
- logo vodi na `/`;
- tačno četiri stavke: O nama, Ponuda, Reference, Kontakt;
- aktivna ruta jasno označena;
- CTA `Kontaktirajte prodaju`;
- mobilni meni sa `aria-expanded` i zatvaranjem nakon izbora.

## Footer

- tamna editorial površina;
- telefon, email i adresa iz centralnih podataka;
- linkovi glavne navigacije i demo ponude;
- automatska tekuća godina;
- bez Avenor sadržaja.

## Responsive

- desktop: logo / centralna navigacija / CTA;
- mobilni: logo, prodajna akcija i menu kontrola; otvoreni meni preko pune širine headera.
